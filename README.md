# 🚀 IntelliGit

IntelliGit is a GitHub profile analytics dashboard that lets users explore any public GitHub profile. It displays profile information, repository details, and key repository metrics through a clean and intuitive interface. AI-powered repository analysis is currently under development.

## ✨ Features

- 🔍 Search any public GitHub profile
- 👤 View profile details (Avatar, Name, Username, Followers, Following)
- 📂 Display all public repositories
- ⭐ View repository stars and forks
- 💻 View primary programming language
- 📝 Repository description
- 🔗 Direct link to GitHub repositories
- 📱 Responsive dashboard interface
